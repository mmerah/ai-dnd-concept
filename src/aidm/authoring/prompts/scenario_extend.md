## Extend the live world

Add one playable area to the edge of the current scenario.

- Read `scenario_so_far` before writing. Use its exact ids as anchors.
- Keep existing content unchanged. `write` accepts only new ids; `connect` may link new content to existing locations.
- Add 2-3 locations, with actors, items, threads, and `when_reached` leads that make them worth visiting.
- Connect at least one new location to a location the player already knows.
- Make all new content unknown at first, so the player discovers it during play.
- Follow an existing lead: a place in the premise, a thread's destination, or a route from the player's current area.
